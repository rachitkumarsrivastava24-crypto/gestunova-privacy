GestuNova Privacy Policy

Last updated: October 17, 2026

1. About GestuNova

GestuNova is a Windows desktop application that allows users to control their computer using hand gestures.

2. Camera Access

GestuNova uses the device camera to detect hand gestures. Camera access is necessary for gesture-control features.

3. Image Processing

Camera frames are processed for gesture recognition. The application also includes a photo-capture feature. How captured photos are handled depends on the application's actual implementation.

4. Personal Information

The basic gesture-control feature is not intended to collect personal information. This statement does not cover information that may be processed by future features or external services.

5. Data Sharing

Before using GestuNova, users should review how the application handles camera frames and captured photos. Data handling will be disclosed accurately if the application adds online services or third-party integrations.

6. Policy Updates

This privacy policy may be updated as GestuNova develops. Changes will be published on this page.

7. Contact

For support, use the contact information provided in the GestuNova Microsoft Store listing.
